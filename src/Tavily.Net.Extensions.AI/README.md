# Tavily.Net.Extensions.AI

Optional `Microsoft.Extensions.AI` tools for the Tavily .NET client.

```bash
dotnet add package Tavily.Net.Extensions.AI
```

Create `AIFunction` tools from an existing `TavilyClient` with
`AsSearchTool()` and `AsExtractTool()`.

See the [AI tools guide](https://github.com/mehdihadeli/tavily-dotnet/blob/main/docs/guide/ai-tools.md)
for usage examples.
