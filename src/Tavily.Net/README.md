# Tavily.Net

Core typed .NET client for the Tavily API.

```bash
dotnet add package Tavily.Net
```

The client supports search, extraction, crawling, mapping, research, usage,
logs, feedback, and keyless search and extraction operations.

See the [repository README](https://github.com/mehdihadeli/tavily-dotnet#readme)
for the full API overview and usage examples.
